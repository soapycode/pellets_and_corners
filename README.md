[***Project from 2022***]

NOTE: This repo contains only the scripts and some example screenshots from the Pac-Man clone I made in Unity, not all of the other project files needed to actually build it.

## Pellets and Corners

PaC for short, this was an exercise in creating a more complete and polished game in Unity rather than all of the little experiments I've done up to this point. It's a recreation of Pacman with all art and programming handled by me. I used an article by [Chad Birch](https://web.archive.org/web/20200702060956/http://gameinternals.com/understanding-pac-man-ghost-behavior) and ["The Pac-Man Dossier"](https://www.gamedeveloper.com/design/the-pac-man-dossier) as game design documents to guide what kind of features were needed.
